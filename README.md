# redes-seguridad

Requisitos:
Python 3.14

#### Índice de Ejercicios

* **Ejercicio 1: Obtención de IP Local** 

  * Obtiene el nombre del equipo y su dirección IP local en la red mediante una conexión UDP de prueba.
* **Ejercicio 2: Calculadora de Red CIDR** 

  * Analiza una red en formato CIDR para calcular la máscara, el prefijo, la dirección de broadcast y los hosts útiles disponibles.
* **Ejercicio 3: Verificador de Ping Individual** 

  * Comprueba si un host o dirección IP específica responde a las solicitudes de ping, adaptando el comando según el sistema operativo.
* **Ejercicio 4: Escáner de Red por Barrido de Ping** 

  * Realiza un barrido de ping concurrente utilizando hilos para identificar de forma rápida todos los hosts activos dentro de un segmento de red.
* **Ejercicio 5: Escáner de Puertos TCP** 

  * Evalúa un listado de puertos conocidos en una dirección IP para determinar cuáles se encuentran abiertos y qué servicios suelen utilizarlos.
* **Ejercicio 6: Resolución de Nombres y DNS Inverso** 

  * Resuelve un dominio para mostrar sus direcciones IP y el tiempo de respuesta, e intenta realizar la resolución inversa de la IP obtenida.
* **Ejercicio 7: Medidor de Latencia TCP** 

  * Mide el tiempo de respuesta y la estabilidad de una conexión TCP hacia un puerto específico a través de múltiples intentos, calculando estadísticas y porcentaje de pérdida.
* **Ejercicio 8: Verificador de Estado HTTP y Vencimiento de Certificado TLS** 

  * Realiza una petición web para obtener el código de estado HTTP y examina el certificado SSL/TLS del dominio para calcular los días restantes antes de su vencimiento.
